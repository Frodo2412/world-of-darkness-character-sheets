# Discipline data review checklist

For the pull request review of `src/domain/v20/disciplineData/`. One row per Discipline, power and field, with the V20 page where the power's entry begins. Page numbers are the printed page numbers of *Vampire: The Masquerade, 20th Anniversary Edition* (chapter four, Disciplines). Tick a row by checking the value against that page.

How the values were read:

- **cost** is what activating the power spends, as its System entry states it. "None" is used when the System entry spends nothing, following the chapter's own note on p. 128: "Unless stated in the description, Disciplines cost no blood or Willpower points to activate."
- **duration** and **difficulty** are left undefined (shown below as _undefined_) when the book does not state a clean value; the Disciplines tab then shows "See rulebook (V20 p. N)".
- **difficulty** also carries the resisting roll or the variable difficulty when that is how the System entry states it. A power with no roll and no resisting roll has no difficulty.
- **prerequisite** is the Discipline and the number of dots that unlock the power, from the dots printed beside its name.
- **summary** is a sentence of the book's description of the power, word for word, except those marked _(condensed)_, which shorten the book's wording.
- **pool** is the roll that existed in the catalogue before this work (unchanged); it is listed so it can be checked in the same pass.
- Celerity (p. 142), Fortitude (p. 158) and Potence (p. 192) keep their one-line notes and Thaumaturgy (p. 212) and Necromancy (p. 159) keep their path note; none of them lists powers, so none has rows here.
